Venue Settings
Door Entry PIN
Gates the standalone scanner reachable from the login screen — never grants database access on its own, only entry to the scan-only UI. Now persists across reloads.
Cashier / Box Office PIN
Gates the standalone Box Office view reachable from the login screen — cash sales only, real seats at the event's listed price. Same posture as Door Entry PIN: gates UI visibility, never grants database access on its own.
Payout & Support Contact
Where resale-payout notifications and buyer support requests get sent. Nothing here has ever been set for this venue — the payout-notification system has been silently inert until these are filled in.
